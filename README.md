# Hieu Tran — personal portfolio

A bilingual portfolio of application development, anonymized professional contributions, and personal experiments in learning and accessibility.

[Visit the portfolio](https://minhhieu04.github.io/).

## Development

Semantic HTML, TypeScript and Vite with locally hosted fonts. Run `npm ci`, then `npm run dev` (port 5177) or `npm run build`.

## Publishing

GitHub Pages serves `main:/docs`. Build locally, replace the previous published output with the reviewed build and retain `docs/.nojekyll`. Commit source and published output together.

## Content boundaries

Client projects are anonymized. Public descriptions cover personal contributions at a high level, without client/product names, identifying imagery, proprietary source, internal architecture, customer data or unverified metrics. Personal projects are distinguished from employment work. SignBridge recognition remains experimental; AIEN is in its foundation phase.

The downloadable CV is the public-facing version. Original application documents remain outside this repository. This update does not remove historical Git versions or external caches.

The toolkit distinguishes application-development experience from infrastructure familiarity. Layout inspiration includes Rahul Jain’s GitHub profile generator; no tracker or remote statistics widget is embedded.
